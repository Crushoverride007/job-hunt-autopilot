# Vetting a posting

Read the full description. Skip (and log a one-line reason) if ANY of these apply, unless the
user's answer bank says otherwise.

## Auto-skip
- **Language:** requires a language the user doesn't have at the level asked
  (e.g. "fluent Dutch", "sehr gute Deutschkenntnisse", "C1 German", "Portuguese required").
  A posting written in a local language usually means the team works in it, unless it says
  "English only".
- **Authorisation:** "EU citizens only", "must have the right to work in X", "no visa
  sponsorship", "valid work permit required", "sponsorship only for candidates already in X",
  "must live within commuting distance" - when the user needs sponsorship.
- **Seniority:** asks clearly more than the user's experience (e.g. 7+ or 10+ yrs for a 5-yr
  profile) or a team-lead / people-manager role they don't want.
- **Deal-breakers** from the answer bank (e.g. client-facing consulting: title "Consultant",
  pre-sales, workshops, advising clients).
- **Duplicate:** same client project via a second agency (same requirements, same city) ->
  skip; applying twice can block both.
- **Not the field:** title matches but content is helpdesk/IT admin, data engineering, etc.
- **Pay far below market** for the location.
- **Freelance / B2B / short contracts** when the user needs sponsorship (rarely sponsored).

## Grey zone (apply, but flag in the batch table)
- One missing tool (e.g. Kafka, Bicep, Sysdig) when the rest fits.
- Asks 1 more year than the user has.
- IT services firm placing engineers at one client long-term ("embedded engineer") -
  OK unless the user excludes it. Interview question to suggest: "Would I be embedded in one
  client's team long-term, or rotating between clients with lots of client meetings?"
- Very high applicant count (500+) - long shot.

## Prioritise
- Posted in the last 24-48h ("early applicant").
- Named job poster / published contact (enables a follow-up).
- Mentions relocation, visa support, sponsorship, or an English-speaking international team.
