# Onboarding (first run only)

Goal: in ~10 minutes, collect everything needed so later sessions never have to ask.

## 1. Get the CV
Ask the user to upload their CV (PDF/DOCX). Read it fully. Extract: name, contact, location,
roles with dates, achievements with numbers, skills, certifications, education, languages.

## 2. Interview (ask in small groups, use tappable options where possible)
1. **Goal:** how many applications, by when? (e.g. 30 in 2 weeks)
2. **Target roles:** titles to search (e.g. DevOps, DevSecOps, Cloud, Platform, SRE).
3. **Seniority:** years of experience; "mid", "senior"?
4. **Locations:** countries/cities; remote OK? on-site OK?
5. **Work authorisation:** citizenship; which countries they can work in without sponsorship;
   visa routes they qualify for (e.g. EU Blue Card with a Master's).
6. **Languages + levels** (CEFR).
7. **Salary:** current (ask currency AND period - monthly vs yearly), expectations per country.
8. **Notice period / earliest start.**
9. **Deal-breakers:** e.g. no client-facing consulting, no on-call, no relocation to X.
10. **Standing answers:** diversity questions (default "Prefer not to say"), privacy-notice
    consent OK?, AI-transcription in interviews?, talent-pool boxes?
11. **Email to use** on applications, phone, postcode.
12. **Years per skill** for common screening questions (propose numbers from the CV and let
    the user correct them). Mark tools they have NOT used so you answer "No" honestly.

## 3. Build the Notion workspace
Use `notion-schema.md`. Create:
- Page "Job Hunt - <Name>" with sections: Goal, Answer bank, Rules, Plan, Dashboard, Backlog.
- Database "Applications" (schema in notion-schema.md) + views.
- Fill the Answer bank from `answer-bank-template.md`.

## 4. CV versions
Offer 1-2 specialised versions (e.g. "Azure / DevSecOps" and "AWS / Platform"): same facts,
different headline, summary order and skill order. Keep one page, single column, plain text
(ATS-safe). Tell the user to upload both to LinkedIn saved resumes and the other job sites, and
to name files clearly (e.g. `AZURE-Name_CV.pdf`).

## 5. One-time checklist for the user
- Log in to LinkedIn, Indeed, StepStone, Monster in Chrome (create accounts themselves).
- Profile headline/location match the CV (recruiters see the profile with Easy Apply).
- Daily job alerts on.
- Delete outdated CVs from LinkedIn saved resumes (Settings > Data privacy > Job application
  settings). Do NOT turn off "save resumes and application data".

## 6. Confirm the goal
"Goal: 30 applications by <date>. Roles: ... Countries: ... I'll bring you batches of ~10 to
approve with one reply." Then start the loop.
